# Source and license notes

Original MoonORC implementation and tests are licensed Apache-2.0 (root LICENSE), developed with AI assistance. No Apache ORC C++/Java runtime code or pyorc binding code is copied or vendored. This is an independent implementation of a restricted interoperable ORC profile, not a full port or Apache-endorsed product.

- [Apache ORC v1 specification](https://orc.apache.org/specification/ORCv1/) and [official format definition](https://github.com/apache/orc/blob/rel/release-1.9.4/proto/orc_proto.proto): sources for byte encodings, wire fields and published encoding examples. Apache Software Foundation, Apache-2.0. A few compact published encoding vectors are included with attribution in `rle_v2.mbt`; no downloaded external dataset is included.
- [moonbit-community/flate](https://github.com/moonbit-community/flate) 0.10.0: Apache-2.0 pure MoonBit raw DEFLATE runtime dependency. ORC framing and column encodings are implemented here, not by this dependency.
- [moonbitlang/async](https://github.com/moonbitlang/async) 0.22.5: Apache-2.0, used only by the native file CLI. Core is provided by the installed MoonBit toolchain under its own license.
- [pyorc](https://github.com/noirello/pyorc) 0.10.0: Apache-2.0, independent Apache ORC C++-based DEVELOPMENT TEST oracle, not a MoonORC runtime requirement. Its binary wheel and dependencies are installed into the ignored local environment and are not committed.
- `fixtures/*.orc` contain only original synthetic values generated by `scripts/interop.py`. `fixture_data_wbtest.mbt` is mechanically embedded fixture DATA, explicitly excluded from effective-code statistics; its generator is supplied. This data is part of the original test artifacts under the project license.
- `tools/windows/path_shim.c`, `build-shim.ps1`, `moon.ps1`: reused Apache-2.0 compatibility tooling from the user's local MoonH5/MoonSparql projects. Original role: normalize extended DOS paths passed to official Moon 20261016 OCaml child tools. They do not modify runtime code or compiler binaries. The root license covers these tools; they do not count as effective MoonBit source.

Apache ORC is a trademark of the Apache Software Foundation. MoonORC is an independent local project. No affiliation, certification, security audit, or exhaustive format compatibility is claimed.
